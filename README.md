# Coin999 夥伴計算機

給 Coin999 玩家用的「孵化 / 耕種夥伴」分數與代幣計算工具。輸入自己與每位隊友的分數，就能看到每位夥伴的完成進度、還差多少分，以及需要投入多少代幣。

純前端靜態網頁，不需要後端或安裝套件，資料只保存在瀏覽器本機。

## 功能

- **四種關卡模式**
  - 🥚 孵化（4 位隊友）
  - 🌱 耕種（4 位隊友）
  - 🏆 黃金孵化（2 位隊友）
  - 👑 黃金耕種（2 位隊友）
- **自訂目標分數**：每種模式可個別設定「每位目標分數」。
- **隊伍總覽**：每位隊友卡片顯示頭像、角色造型與雙色進度條（自己 / 隊友各佔多少）。下方顯示隊伍總目標分與完成進度。
- **個別計算頁**：點擊隊友卡片進入，輸入自己與隊友分數後計算：
  - 目前總分、目標分數
  - 一整顆還差多少分、需要多少代幣
  - 責任分（還差分數的一半）與對應代幣
- **SVG 角色造型**
  - 孵化：坐在石台上的綠色傘蜥（紫色頸傘、大眼睛）
  - 耕種：種在圖騰花盆裡的食人花（粉紅厚唇大笑）
  - 黃金模式會自動換成金色配色並加上發光效果
- **多國語言**：繁體中文、English、Tiếng Việt、日本語、한국어、ไทย、Indonesia、Español、Português BR。
- **媒合平台**：玩家可貼上遊戲交友連結、暱稱、目前代幣，並點選已完成幾隻來找人幫忙（徵求列表會顯示完成進度），想幫忙的人可以一鍵複製好友連結、加好友並留言。
  - 普通孵化需 14,500 代幣以上、普通耕種需 7,500 代幣以上（能自己完成一半）才可發文，送出前會再跳出警告確認；黃金模式不限。
  - 免登入，每台裝置自動產生一組身分，只有發文的裝置能刪除自己的貼文；貼文只顯示最近 3 天。
  - 可附上遊戲截圖連結（選填，只接受 Imgur、ImgBB、Postimages、Google 相簿／雲端硬碟）。

  **防濫用機制**

  - 只接受 Coin Master 官方交友連結（`https://getcoinmaster.com/~...`），擋掉釣魚網站與短網址。
  - 一個交友連結同時只能有一篇徵求（不分模式）；發文後 24 小時內就算刪除也不能重發，避免刪文洗掉舉報、重新置頂。
  - 被舉報次數以交友連結累計並顯示在貼文上，刪文重發也不會歸零。
  - 貼文與留言都可以舉報（例如發文者不實、幫忙者沒出力），管理員可在試算表一鍵封鎖。
  - 發文者本人的留言會顯示「作者」標籤，避免被冒充；暱稱與留言不可夾帶連結或網址。
  - 每台裝置與全站都有發文、留言、舉報的頻率限制，避免被程式大量洗版。
  - 有新舉報時自動寄 email 通知管理員。
  - 資料存在 Google 試算表，透過 Google Apps Script 讀寫，完全免費（設定方式見下方）。
- **本機保存**：所有設定與分數自動存到 `localStorage`，可用「重置所有設定」一鍵恢復預設值。

## 代幣換算

代幣需求 = `ceil(分數 × 代幣 / 分數基準)`，換算比例定義在 `app.js` 的 `RATES`：

| 類型 | 代幣 | 分數 | 使用模式 |
| --- | ---: | ---: | --- |
| 孵化 | 14,500 | 170,000 | 孵化、黃金孵化 |
| 耕種 | 7,500 | 90,000 | 耕種 |
| 黃金耕種 | 47,000 | 1,120,000 | 黃金耕種 |

預設每位目標分數（可在頁面上修改）：

| 模式 | 預設目標 |
| --- | ---: |
| 孵化 | 340,000 |
| 耕種 | 180,000 |
| 黃金孵化 | 1,900,000 |
| 黃金耕種 | 1,120,000 |

## 使用方式

`app.js` 以 ES module 載入，直接用 `file://` 開啟 `index.html` 無法執行，請用任一靜態伺服器啟動：

```bash
python -m http.server 8000
```

然後在瀏覽器開啟 <http://localhost:8000>。

也可以直接部署到 GitHub Pages 等靜態網站服務。

## 專案結構

```
.

└── backend/
    └── apps-script.gs  # 媒合平台後端（Google Apps Script）
```

## 媒合平台設定

GitHub Pages 只能放靜態檔案，所以媒合平台的資料存在 Google 試算表，由 Google Apps Script 提供 API。全部免費，只需要一個 Google 帳號。

1. 到 [Google 試算表](https://sheets.google.com) 建立一個新的空白試算表（例如命名為「Coin999 媒合平台」）。
2. 在試算表選單點「擴充功能 → Apps Script」。
3. 把編輯器裡預設的程式碼全部刪掉，貼上 [`backend/apps-script.gs`](backend/apps-script.gs) 的完整內容，按儲存。
4. 點右上角「部署 → 新增部署作業」：
   - 類型選「網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，第一次會要求授權，用你自己的 Google 帳號允許即可（若出現「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）」，因為這是你自己寫的腳本）。
5. 複製部署完成後的「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。
6. 打開 [`match.js`](match.js)，把網址貼到最上方：

   ```js
   const MATCH_API_URL = "https://script.google.com/macros/s/.../exec";
   ```

7. 更新 `index.html` 與 `app.js` 裡的 `?v=` 版本號後 commit、push，GitHub Pages 更新後就能使用。
8. 開啟舉報 email 通知：在 Apps Script 編輯器上方的函式選單選 `sendTestEmail` → 按「執行」，依指示授權寄信權限；收到測試信就完成了。通知預設寄到部署者的信箱，要改寄別的信箱請修改 `ADMIN_EMAIL`。

使用後會自動在試算表建立 `Posts`（貼文）、`Comments`（留言）、`Reports`（舉報）、`Bans`（封鎖名單）工作表。

**管理與注意事項**

- **處理舉報、封鎖玩家**：
  1. 打開試算表後上方會出現「媒合平台」選單（第一次使用需重新整理試算表並授權）。
  2. 收到舉報通知信後，到 `Reports` 工作表選取要處理的列（`type` 欄：`post` 是貼文被舉報、`comment` 是留言被舉報）。
  3. 舉報成立：點「媒合平台 → 封鎖選取列的玩家」。
     - 貼文舉報：封鎖發文者的交友連結與作者ID，並隱藏他的貼文。
     - 留言舉報：只封鎖留言者，不會影響他留言的那篇貼文。
     - 被封鎖的人之後無法再發文或留言，該筆舉報的 `handled` 會自動改成 `TRUE`。
  4. 舉報不成立：把該列的 `handled` 欄改成 `駁回`，就不會列入貼文上的被舉報次數。
  5. 解除封鎖：到 `Bans` 工作表刪除對應的列。
- **通知信**：同一個被舉報對象 30 分鐘內只寄一封、每天最多 50 封，避免信箱被灌爆；完整紀錄都在 `Reports` 工作表。
- **手動隱藏內容**：把該列的 `deleted` 欄改成 `TRUE` 即可隱藏（貼文或留言都一樣）。
- **修改後端程式**：改完 Apps Script 後要「部署 → 管理部署作業 → 編輯 → 版本選『新版本』→ 部署」，網址不變。
- **調整規則**：都在 `apps-script.gs` 最上方——顯示天數 `POST_TTL_DAYS`、重發冷卻 `REPOST_COOLDOWN_HOURS`、代幣門檻 `MIN_TOKENS`、各模式隻數 `CREATURE_COUNT`、頻率限制 `RATE_LIMITS`、截圖網站 `SCREENSHOT_HOSTS`。前端 `match.js` 也有 `MIN_TOKENS`、`CREATURE_COUNT`、`COIN_LINK_RE`、`SCREENSHOT_HOSTS`，兩邊要一致。
- **列表快取**：列表會快取 20 秒以減少讀取試算表；直接在試算表手動修改資料時，最多 20 秒後網頁才會更新。
- **免費額度**：Apps Script 免費帳號有同時執行數量（約 30 個）等配額限制，一般活動規模足夠；尖峰時若太多人同時發文，會提示稍後再試。
- **身分與安全**：每台裝置的身分金鑰只存在該瀏覽器，後端只保存其雜湊值（作者ID）。清除瀏覽器資料或換裝置後就無法刪除舊貼文（3 天後會自動下架，或由管理員隱藏）。試算表本身不需要公開分享，外部只能透過 API 讀到貼文與留言。
- **已知限制**：沒有登入機制，有心人仍可用第二個遊戲帳號（新交友連結）搭配無痕視窗（新裝置身分）繞過封鎖；目前的機制只能提高成本。

## 開發備註

- **新增語言**：在 `i18n.js` 的 `SUPPORTED_LANGS`、`LANGUAGE_META` 與 `I18N` 加上對應項目。
- **調整換算比例或預設目標**：修改 `app.js` 的 `RATES` 與 `DEFAULT_DATA.targets`。
- **修改角色造型**：`app.js` 的 `getLizardSvg()`（孵化）與 `getPlantSvg()`（耕種），各自有一般與黃金兩組配色。
- **快取版本**：修改 CSS / JS 後，請同步更新 `index.html`、`app.js`（import `i18n.js`、`match.js`）與 `match.js`（import `match-i18n.js`）的 `?v=` 版本號，讓使用者立即載入新檔案。
- **本機資料 key**：`coin999_partner_calc_v10_multilang_timezone`，若資料結構有不相容變更可更換 key。
